## 2. 🔴 VRT ベースラインの測り方（#940 / #951 で確立。次に描画を変える人が必ず読む）

**閾値を一時的に 0 にしてから測る。**

```bash
npm run build                       # e2e は本番ビルドを再利用する。main が進んでいたら必ず先に
# 3 spec の maxDiffPixelRatio を一時的に 0 へ:
#   tests/e2e/kiosk-vrt-a11y.spec.ts / admin-vrt-a11y.spec.ts の SHOT_BASE
#   tests/e2e/kiosk-screenshot.spec.ts
npx playwright test kiosk-screenshot.spec.ts kiosk-vrt-a11y.spec.ts admin-vrt-a11y.spec.ts \
  --update-snapshots=none           # ← どの枚が落ちるかを数える
# 落ちた枚の差分画像を 1 枚ずつ見る → 期待どおりなら該当テストだけを名指しして
npx playwright test <spec> -g "<テスト名>" --update-snapshots=changed
git checkout -- tests/e2e/*.spec.ts # 閾値を戻す
npx playwright test ... --update-snapshots=none   # 既定閾値で 16/16 pass を確認
```

- 🔴 **既定の `maxDiffPixelRatio: 0.002` は変更そのものを吸収する。** #918 の罫線変更は
  既定閾値だと 16 枚とも緑で、**閾値 0 にして初めて 4 枚が出た**。`--update-snapshots=changed`
  を既定閾値で回すと、stale が**永久に残り続ける**
- 🔴 **`--update-snapshots=all` を使わない。** 描画が変わっていない PNG まで再エンコードされ、
  バイト差だけの変更に本物が埋もれる
- `kiosk-landscape-out-of-hours` は閾値 0 だと**mask 済みの日付**で常に落ちる。本変更と無関係
  なので**更新しない**（spec に「唯一この 1 枚が許容値 0 で落ちる」と注記がある）

### 🔴 枚数が合っても中身は合っていない

`docs/handoff-2026-09-03.md` §0 の表は stale の 1 枚目を

## 3. #816 で得た配線の教訓（次に UI を触る人へ）

### 🔴 React Compiler は「渡された ref への代入」を error にする

`react-hooks/immutability` が
`Cannot modify local variables after render completes` / `This value cannot be modified` を出す。
**`useCallback` で括っても通らない。** 解は ref を 2 つ持たず、
**渡された ref をそのまま `ref` に渡して `.current` を読むだけ**にすること。

🔴 **この refactor は穴を作った。** ref の統一を誤ると `KioskFlow` の `escapeBarRef` に node が
入らず `--kiosk-chat-safe-bottom` が既定のまま残り、**チャット FAB が逃げ道バーに重なる**
（#121 H1 の再発）。**既存テストは 1 本も落ちなかった** —— 変異検証で初めて出た。
バーの実測高さが持ち上げ量へ渡っていることを直接主張するテストを足して塞いである。

### 逃げ道バーの幾何（実測・1024x768 の相手選択）

| 位置 | バー上端 | 本文下端 | 覆い |
| --- | --- | --- | --- |
| 初期着地 `scrollY=0` | 652 | 971 | あり |
| スクロール末端 `scrollY=407` | 612 | 588 | なし（バーは viewport 下端から **40px 浮く**） |

🔴 **末端でバーは下端に付かない**（`.screen` の下余白ぶん）。さらに本文終端はバー上端の
24px 上にある。「末端から少し戻せば覆いが始まる」は**成り立たない**ので、テストで戻し量を
決め打ちにしないこと（覆いが始まるまで少しずつ戻して測る）。

**用件選択画面も 1080x810 で覆われていた** —— 監査も #816 本文も相手選択しか挙げていない。

### 🔴 消す前に MERGED を 1 本ずつ引く

台帳の旧リストに **PR #944 が CLOSED（未マージ）のブランチ**が混ざっていた。
そのまま流していたら**作業ごと消えていた**。「squash だから `git branch -d` が失敗する」は
**マージ済みの証拠にならない**（`-d` は未マージでも失敗する）。

```bash
for b in $(git ls-remote --heads origin | sed 's#.*refs/heads/##' | grep -v '^main$'); do
  st=$(gh pr list --head "$b" --state all --json state --jq '[.[].state] | join(",")')
  case "$st" in *MERGED*) echo "$b" ;; *) echo "skip: $b [${st:-PR なし}]" >&2 ;; esac
done
```

## 6. 環境メモ（このセッションで踏んだもの）

- 🔴 **ローカル `--fast` は 2 本の偽の赤を出す**（#952）。
  `src/lib/runtime-policy/store.test.ts` の「確定と報告した state は…」と
  `tests/config/lint-warning-budget.test.ts`。どちらも `Test timed out in 5000ms` で
  **アサーションに到達する前**に落ちる。同日のクラウド `--full` では**全部 PASS**。
  ローカルの赤はまずこれを疑い、委譲時は `localFastGate: "failed"` で正直に申告する
- 🔴 **ゲートログを `| tail -N` で捨てない。** どのテストが落ちたか分からなくなり、
  取り直しに 9 分払った。全文をファイルへ落としてから読む
- **`SSH_AUTH_SOCK` が Bash ツールに来ない。** `/private/tmp/com.apple.launchd.*/Listeners`
  を export すると署名コミットが通る（`--no-verify` で回避しないこと）
- zsh の `for b in $VAR` は**単語分割しない**（`${=VAR}` が要る）。`cp` は `-i` エイリアス
  （スクリプト内では `command cp -f`）。`sed` は `sd`、`find` は `fd` に化ける
- **`docs/loop-queue.md` は競合ホットスポット。** 本セッション中だけで別セッションが 10 本以上
  マージしている。委譲文には「競合したら両方の節を残す」と書くこと
