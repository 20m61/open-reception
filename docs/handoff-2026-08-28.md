## 4. 今日確定した環境の事実（**再調査しないこと**）

### GitHub のレート制限は「別々のバケツ」

🔴 **`gh api rate_limit` はこのセッションの消費を映していない。**

| 見るもの | 実測 |
| --- | --- |
| `gh api rate_limit` | `limit 5000` / `used 0`。**REST を 3 回叩いた後も 0 のまま** |
| 実リクエストの `X-Ratelimit-*` ヘッダ | `limit` **12500**・`used` が 1 ずつ増える。**これが実際のバケツ** |
| MCP GitHub | **さらに別。** `gh api` が通り続けている最中に約 25 分間 429 相当を返した |

連続サンプルで `used` が **31 → 8 と減った**ことがある＝ REST 側も 1 トークンではない。
**MCP のバケツは中から観測も事前判定もできない。**

→ 対策は済んでいる: MCP でしか出来ない操作は実質 draft 解除だけなので、
`scripts/create-pull-request.ts` が **`--draft` を理由付きで拒否**する（#824）。

### リモートブランチの削除は 2 経路とも塞がっている

- `git push origin --delete` … 403 では返らず、`send-pack: unexpected disconnect` の後に
  🔴 **`Everything up-to-date`** を出す（**最後の 1 行だけ読むと消えたように見える**）
- `gh api -X DELETE .../git/refs/heads/<branch>` … HTTP 403 `Write access ... not permitted through this proxy.`

`.claude/settings.json` の許可が外すのは**ホスト側のプロンプトだけ**で、proxy には効かない。
削除を報告する前に `git ls-remote --heads origin | grep <branch>` で確かめること。
