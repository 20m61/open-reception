```

  commit_title="feat(kiosk): 担当者グリッドを部署で段階開示する (#787)")
```

- **MCP GitHub のレート制限は自分のトークンとは別**。`gh api rate_limit` が 5000/5000 でも
  MCP は落ちる
- **`gh` の GraphQL はブロック**されている。REST 代替が無い操作（draft 解除）は MCP 必須
- **リモートブランチの削除がプロキシに拒否される**。マージ済みブランチが溜まるので
  ローカルで `git push origin --delete` すること
- **コンテナは ephemeral**。環境変数の反映も、インストールしたツールも、次のセッションでは
  やり直し
