こちらは**規約そのものを書き換えたループ**の記録である。

- 追記は **append-only**（既存行の書き換え・削除はしない）。
- **`NO_CHANGE` も必ず記録する。** 記録しないと「回っていない」と「回したが変えるに
  値しなかった」が区別できず、`never_run` と正常運転が同じ見た目になる。
- 規約版は `.claude/rules/opus5-autonomous-loop.md` の
  `<!-- loop-rules-revision: N -->` と一致していること（食い違いは `revision_drift`）。
