## 6. 次に触る人が最初に読むところ —— **今回の失敗 3 つ**

### 6-a. 見積もりを 3.5 倍外した（課題 24）

`docs/loop-queue.md` に「罫線を持つ**全要素**の描画が変わる。darwin 14 枚は macOS でしか
作れないので着手はコスト込みの判断」と書いていた。**実測したら動いたのは 4 枚だけ**だった。

外した理由は**測らずに書いた**こと。実際には (a) 装飾用トークンを触っていない、
(b) 主要 CTA は罫線ではなく背景で塗られている、の 2 点で 12 枚が画素単位で同一だった。

**「規模が大きいから判断が要る」と書くときは、規模を測ってから書く。**

### 6-b. VRT の許容値が変更そのものを吸収していた

上の 4 枚は **`maxDiffPixelRatio: 0.002` では 16 枚とも緑**で、許容 0 にして初めて出た。
本リポジトリが**これで 3 度退行を隠している**（第 77 / 95 / 96 wave）のに、4 度目を踏みかけた。

**描画を変える変更では、緑を「変わっていない」と読まない。**

### 6-c. 検出器が自分のコメントを誤検出した（#920）

`tests/config/responsive-strategy.test.ts` の初版が `globals.css` の**コメント**
（「1280〜1600px の 3 ペインレイアウトで…」）をしきい値の直書きとして落とした。
`CLAUDE.md`「調査の作法」が名指ししている型で、**それを読んだうえで踏んだ**。
`stripComments()` を通してから走査している。

あわせて、同じ検出器で変異 M2（別ファイルに `const LARGE = 1600;` と書き直す）が
**生存した** —— 検出器が `1600px` と定数名しか見ていなかった。`\b1600\b` へ直し、
7 種を当て直して kill が減っていないことを確認した
（`.claude/rules/opus5-autonomous-loop.md`「方式を替えたら、前の方式が守っていた変異を当て直す」）。

## 7. 環境メモ

- 🔴 **`gh` CLI がクラウドセッションに存在しない。** `scripts/create-pull-request.ts` /
  `merge-pull-request.ts` は**内部で `gh api` を呼ぶ**ので、クラウドでは
  `command not found` で exit 4 になる（本セッションで実測。`.claude/skills/loop-round`
  が名指ししているのはこのスクリプトなので、**スキルどおりにやると落ちる**）。
  クラウドでは GitHub MCP ツール（`create_pull_request` / `merge_pull_request`、
  `merge_method: "squash"`）を使った。**macOS には `gh` があるのでスクリプト経路へ戻せる**
  ——「スクリプトが壊れている」わけではない
- **semgrep が未導入**でゲートが `SKIP` する（`--strict` では FAIL）。#841 でルールは固定済み
- 品質ゲートのスタンプは**作業ツリーに紐づく**。クラウドで取った green はローカルへ持ち運べない
